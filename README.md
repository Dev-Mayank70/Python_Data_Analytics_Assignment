# Python Programming for Data Analytics

A beginner-level Python programming project developed as part of a Data Analytics foundation assignment.

The project covers Python programming fundamentals including variables, data types, operators, conditional statements, loops, functions, strings, collections, file handling, and a mini Student Record Management System.

## Project Overview

This assignment is designed to build a strong foundation in Python programming for Data Analytics.

The project contains nine tasks:

1. Python Basics
2. Variables & Data Types
3. Operators and Calculator
4. Conditional Statements
5. Loops
6. Functions
7. Strings & Collections
8. Basic File Handling
9. Student Record Management System

## Task Details

### Task 1 – Python Basics

Demonstrates basic Python input and output operations. The program accepts the student's name, college name, and branch and displays the information in a formatted manner.

### Task 2 – Variables & Data Types

Demonstrates Python's basic data types:

* Integer
* Float
* String
* Boolean

The `type()` function is used to identify the data type of each variable.

### Task 3 – Operators

A simple calculator demonstrates:

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

### Task 4 – Conditional Statements

A grading program uses `if`, `elif`, and `else` to assign grades based on marks.

### Task 5 – Loops

Demonstrates:

* Printing numbers from 1 to 20 using a `for` loop
* Generating a multiplication table
* Printing even numbers from 1 to 50 using a `while` loop

### Task 6 – Functions

Demonstrates user-defined functions for:

* Calculating the square of a number
* Calculating the average of three numbers

### Task 7 – Strings & Collections

Demonstrates:

* String operations
* List operations
* Tuple creation and indexing
* Dictionary key-value storage
* Set operations

### Task 8 – File Handling

Demonstrates how to:

1. Create a text file
2. Write data to the file
3. Read the file
4. Display the contents

### Task 9 – Student Record Management System

A command-line mini-project that allows users to:

* Add student records
* Display all records
* Search for a student by name
* Delete a student record
* Exit the application

Student records are stored using a list of dictionaries.

## How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-data-analytics-assignment.git
```

Move into the project:

```bash
cd python-data-analytics-assignment
```

Run any task:

```bash
python src/Task_1.py
```

For the Student Record Management System:

```bash
python src/Task_9.py
```
